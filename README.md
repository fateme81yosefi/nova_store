# NOVA Store

فروشگاه NOVA با Next.js و App Router. داده از [FakeStoreAPI](https://fakestoreapi.com) می‌آید. ورود و پرداخت ندارد.

## اجرا

Node 20 یا جدیدتر.

```bash
npm install
cp .env.example .env
npm run dev
```

`http://localhost:3000` را باز کن. زبان پیش‌فرض فارسی است و آدرس‌ها با `/fa` و `/en` شروع می‌شوند.

بیلد:

```bash
npm run build
npm start
```

## ساختار

پوشه‌ها را تا جایی که Next اجازه می‌دهد مثل سند گذاشتم.

- `app/[locale]` صفحه‌ها و layout.
- `src/i18n.ts` کانفیگ next-intl است. `i18n/routing.ts` را جدا کردم چون `proxy.ts` نباید ماژول سرور را بکشد داخل خودش.
- `src/proxy.ts` کنار `app` است. Next 16 همان‌جا دنبالش می‌گردد، نه بیرون از `src`.
- `dictionary` متن‌ها. توی JSX جملهٔ ثابت ننوشتم.
- `api/client.ts` همان AxiosInstance است. درخواست‌ها در `requests`.
- سبد خرید با Zustand است و در `storage/cartStore.ts` نشسته، چون داده را همان‌جا در localStorage نگه می‌دارم.
- تم با Context است.
- `robots.ts` و `sitemap.ts` زیر `app` هستند.

فونت وزیرمتن را با fontsource و فایل `assets/Fonts/vazirmatn.css` آوردم، نه next/font، که برای هر دو پروژه یک جور باشد.

## رفتار فروشگاه

محصول‌ها سمت سرور گرفته می‌شوند و فیلتر، مرتب‌سازی و صفحه‌بندی روی همان لیست در کلاینت است. API صفحه ندارد. هر صفحه ۶ محصول است.

جستجو، دسته، مرتب‌سازی و شماره صفحه توی query string می‌مانند تا با رفرش نپرند.

سبد بعد از رفرش می‌ماند. تعداد هر ردیف از ۱ پایین‌تر نمی‌آید. حذف ردیف جداست.

دکمه تسویه غیرفعال است. پرداخت توی محدودهٔ کار نبود.

فرم خبرنامه فقط اعتبارسنجی می‌شود و جایی ارسال نمی‌شود.

تصویر هیرو را از خود عکس محصولات API چیدم. فایل تبلیغاتی جدا نداشتیم.

## قیمت

API دلار می‌دهد. برای نزدیک شدن به طرح، موقع نمایش هر دلار را ۵۰ هزار تومان حساب می‌کنم. این نرخ فقط نمایشی است.

## محدودیت API

اگر FakeStore قطع باشد، صفحه خطا نشان می‌دهد و بالا آمدن برنامه به آن گیر نمی‌کند (`force-dynamic`). دادهٔ POST این پروژه را لازم ندارد.

صفحه را داینامیک گذاشتم چون نمی‌خواستم `next build` به در دسترس بودن API وابسته باشد.
